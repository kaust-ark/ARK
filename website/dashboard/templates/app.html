Welcome to Idea2Paper 👋

One quick step before you launch research: add an API key. We strongly recommend OpenRouter — one key powers the entire pipeline. With a single-vendor key (only OpenAI or only Anthropic), AI concept figures and Deep Research are unavailable — they need Gemini or OpenRouter.

💰 Recommended model: DeepSeek V4 Pro (via OpenRouter) — a full paper typically costs ~$5, about 10× cheaper than GPT/Claude flagship models, with solid results.
🔐 Your keys are stored encrypted (per-user key derivation, AES/Fernet) and used only for your own projects. Best practice: create a dedicated API key with a spending cap, and revoke it when you're done. Manage keys anytime in Settings.

User Settings & API Keys

💡 Bring Your Own Key: Keys are stored encrypted and used only for your own research projects. Best practice: create a dedicated key with a spending cap and revoke it when you're done.
How is my key stored? Encrypted at rest with AES/Fernet; the encryption key is derived per user via PBKDF2-SHA256 (100k iterations), so one account's data cannot decrypt another's. The key is decrypted server-side only while your own project is running — the agents need it to call the model API on your behalf. This is server-side (not end-to-end) encryption, which is exactly why we recommend a capped, dedicated key that you revoke after use.

How to set up:
1. Create a classic PAT with the repo scope, then paste it in the PAT box above. (Fine-grained PATs can't create repos — use a classic one.)
2. Organization (optional): to keep all project repos under one org, create the org on GitHub first — ARK can't create orgs for you — then put its name in the Org box. Leave blank to use your personal account.
Each project then auto-creates a private repo ark-<project> (in the org if set, else <you>/ark-…) and pushes its commits there. The PAT is stored encrypted and used only by the orchestrator — never exposed to the research agents.
